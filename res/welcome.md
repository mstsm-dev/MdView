# MdView

軽量な Markdown ビューアです。ファイルをドラッグ＆ドロップするか、**Ctrl+O** で開いてください。

| キー | 機能 |
|---|---|
| Ctrl+O | 開く |
| F5 | 再読み込み |
| Ctrl+E | エディタで開く |
| Ctrl+F / F3 / Shift+F3 | 検索 / 次を検索 / 前を検索 |
| Ctrl+ホイール / Ctrl++ / Ctrl+- / Ctrl+0 | 拡大・縮小 |
| Ctrl+D | ダークテーマ |
| Ctrl+U | ソース表示 |
| Alt+← / BackSpace | 戻る |
